# Helium Solar – Solar Energy Management App

A Flutter-based mobile application for solar project management, designed to provide project information and progress tracking through a mobile interface.

## Technologies Used
- Flutter
- Dart
- REST API Integration

## Key Features
- Solar project dashboard
- Project listing
- Project progress tracking
- API-based data integration
- Responsive user interface
- Application navigation

## My Contributions

- Worked on responsive UI and navigation.
- Debugged UI and API integration issues.

- `lib/` – Application source code
- `assets/` – Application assets
- `pubspec.yaml` – Project dependencies and configuration
